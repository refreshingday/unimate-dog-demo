# UniMate dog demo

A procedurally built, rigged dog animated from text prompts with [UniMate](https://github.com/Friedrich-M/UniMate). The page also shows UniMate's eagle, shark and Unitree Go2 examples.

- `index.html`: the demo page, which uses `<model-viewer>` for the 3D viewer
- `models/`: animated GLBs
- `gifs/`: rendered clips
- `build_dog.py`: the Blender (bpy) script that builds and rigs the dog

UniMate's code is MIT-licensed, but its checkpoints are CC BY-NC 4.0, so the generated motions are for non-commercial use only.
